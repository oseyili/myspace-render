MySpace Hotel API Overview

MySpace Hotel provides API-ready workflows for hotel distribution, live availability, rates, reservations, cancellations, and booking synchronization.

Core Endpoints

  • GET /api/hotels
  • GET /api/rooms
  • GET /api/rates
  • GET /api/availability
  • POST /api/reservations
  • POST /api/cancellations
  • POST /api/modifications

Partner access is reviewed before production use. Contact: reservations@myspace-hotel.com
