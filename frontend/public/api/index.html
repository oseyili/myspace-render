MYSPACE HOTEL

MySpace Hotel API Overview

MySpace Hotel supports hospitality distribution workflows for live availability, rates, reservations, cancellations, modifications, and partner connectivity.

Availability

GET /api/availability

Rates

GET /api/rates

Hotels

GET /api/hotels

Rooms

GET /api/rooms

Reservations

POST /api/reservations

Cancellations

POST /api/cancellations

Modifications

POST /api/modifications

Webhooks

POST /api/webhooks/:partner

Authentication

Partner API access is reviewed and uses secure token-based authentication for approved integration partners.
