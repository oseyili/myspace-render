MYSPACE HOTEL

API Overview

Partner API workflows are designed for hospitality distribution, live search, availability, rates, reservations, cancellations, modifications, and webhook event handling.

Developer centre Webhook events Partner onboarding Request API access

Core endpoints

GET /api/hotels

List or search approved hotel inventory.

GET /api/rooms

Retrieve mapped room types and occupancy rules.

GET /api/rates

Retrieve mapped rate plans and price structures.

GET /api/availability

Check date, room, guest, and inventory availability.

POST /api/reservations

Create reservation and booking reference workflow.

POST /api/cancellations

Request cancellation workflow.

POST /api/modifications

Modify dates, guest details, room count, or status where supported.

POST /api/webhooks/:partner

Receive partner events for reservation and inventory synchronization.

Authentication

Production partner access requires approval. API access uses secure token-based authentication, partner identifiers, audit logs, and event monitoring.
