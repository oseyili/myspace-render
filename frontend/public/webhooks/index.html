MYSPACE HOTEL

Webhook Events

Webhook workflows help PMS providers, channel managers, and distribution partners synchronize reservation and inventory activity with MySpace Hotel.

API overview Developers Partners Request webhook setup

reservation.created

New reservation created or received.

reservation.modified

Dates, room count, guest, rate, or status changed.

reservation.cancelled

Booking cancellation workflow triggered.

availability.updated

Inventory, stop sell, or room availability updated.

rate.updated

Rate plan, currency, price, tax, or restriction updated.

mapping.updated

Hotel, room, rate, policy, or occupancy mapping changed.

{
  "event": "reservation.created",
  "event_id": "evt_MSH_EXAMPLE",

}

Security model

Approved integrations should use signed webhook payloads, HTTPS endpoints, event IDs, replay protection, retries, and audit logs.
